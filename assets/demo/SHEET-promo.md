# 업종 데모 — 대기 화면 모션 광고 사진 시트 (세로 3:4)

`이미지규격.md` §1 을 따른다 — 피사체는 **위에서 15~60%**, **아래 40% 는 비운 어두운 바탕**(키커 · 제목 · 설명이 얹히고 그늘이 깔린다),
**사진 안 글자 · 로고 · 얼굴 없음**, 어두운 바탕 + 한쪽 빛. Flow 에 4:5 가 없어 3:4 로 뽑는다(무대 0.90 이라 세로가 조금 더 잘린다).
뷰티는 채널 톤 중 「어두운 바닥 + 측면광」 벌로 — 흰 대리석은 흰 글자가 안 읽힌다.
