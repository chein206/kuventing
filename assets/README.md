# 원본 이미지 넣는 곳

여기에 사진을 넣고 아래를 실행하면 화면 규격에 맞게 처리돼 `app/public/img/` 로 나온다.
원본은 건드리지 않는다.

```bash
npm --prefix kuventing/app run img
```

## 파일 이름 규칙

이름 앞부분으로 용도를 구분한다.

| 파일 이름 | 쓰이는 곳 | 처리 |
|---|---|---|
| `ad-차슈덮밥.jpg` | 초기화면 광고 슬라이드 | **자르지 않음.** 긴 변 1600px 이내로 축소만 |
| `prize-a.jpg` | A상 상품 사진 | 1000×1000 정사각 (**원형으로 잘림**) |
| `prize-last.jpg` | 막차 보너스 | 1000×1000 |
| `ticket-01.jpg` | 티켓 아트 | 배경 제거 → 투명 PNG (현재는 SVG로 대체됨) |
| `logo.png` | 매장 로고 | 512×512 |

- 확장자는 `.jpg` `.png` `.webp` 아무거나. 한글 파일명 가능
- 매장이 둘 이상이면 `prize-cafe-a.jpg` 처럼 매장을 끼워 넣고, SQL로 캠페인별 지정

## 비율

**광고는 아무 비율이나 괜찮다.** 가로 4:3이든 세로 3:4든 정사각이든 안 자른다.
화면에서 같은 사진을 흐리게 깔고 그 위에 원본을 통째로 얹는 방식이라 여백이 생기지 않는다.

**상품 사진은 정사각(1:1)이 가장 안전하다.** 다른 비율로 넣어도 스크립트가
배경색을 추정해 피사체를 찾아 정사각으로 잘라준다. 어두운 배경·흰 배경 모두 처리된다.

## 찍을 때 주의

- **상품 사진은 원으로 잘린다.** 피사체를 정중앙에 두고 가장자리 15%는 잘린다고 볼 것.
  접시 전체보다 클로즈업이 낫다
- **광고 사진은 아래 3분의 1에 어두운 그늘이 깔리고 메뉴명·가격이 얹힌다.**
  중요한 피사체를 사진 위쪽~가운데에 둘 것. 사진 안에 글자 넣지 말 것
- **여러 장을 만들 때 톤을 통일할 것.** 하나는 검은 배경, 하나는 흰 배경이면
  슬라이드가 넘어갈 때 화면이 번쩍인다
- 장당 300KB 이하 JPEG면 충분하다

## 실행 후

스크립트가 마지막에 붙여넣을 SQL을 출력한다. 그대로 Supabase SQL Editor에 넣으면 된다.
매장이 여럿이면 캠페인을 지정하도록 손봐서 쓸 것 (`supabase/seed_cafe_images.sql` 참고).

## 무형 상품

할인권처럼 사진이 없는 상품은 SVG로 만들어 뒀다 — `app/public/img/prize-e.svg`.
금액 텍스트만 고치면 2,000원권·3,000원권도 만들 수 있다.
