## 7. 자료조사 반영 (10-19, `research/RESEARCH-2026-10-19.md`)

- **먼저 연락 DM 은 법 확인 전까지 보류** — 정보통신망법 50조: 영리 광고는 매체 상관없이 사전 동의(SNS 쪽지 포함으로 봄), 사업자 상대도 예외 없음, 과태료 750만 → 3,000만원. 동의 요청 자체도 광고로 볼 수 있다. 대신: 큐레이션 계정에 뜬 럭키드로우 팝업에 진짜 댓글(홍보 X) · 박람회 현장에서 명함 + 「자료 보내도 될까요」 동의 · 콘텐츠로 인바운드
- **가상 브랜드 데모는 「데모」 표기** — 화면 한 귀퉁이 + 캡션(`?shoot=1` 판엔 띠가 없으니 편집에서 얹는다). 실제 고객 사례처럼 보이면 기만 광고 소지
- **대표 10-19 정정: 「AI 티」 = SNS 카드뉴스의 정형화된 틀**(큰 번호 · 붓 밑줄 · 진행 표시 · 칸 나눈 카드 · 빈 상자 그림). 음식 · 상품 같은 시각 재료는 넣는다(판 사진 써도 됨). 실촬영 · 실물 사진은 있으면 더 좋음(촬영 S8)
- 숫자(줄 몇 % 등)는 실제 고객 데이터 전엔 안 씀. 「100% · 꽝 없음」 은 사실이어야 하고 남은 수는 실제와 같게
- 인스타: 순위 신호 = 시청 시간 · 도달당 좋아요 · **도달당 보내기**. 해시태그 5개까지(25-12~) → 캡션 첫 줄 검색어가 중요
- **형식(대표 10-19): 「움직이고 체감이 크니 릴스를 많이」 → 주 3회 = 릴스 2~3 + 카드 0~1.** 디자인 · 제작은 모션그래프 세션과 같이(요청서), 게시는 이 세션
- 경쟁: 직접 경쟁은 터치라이크(스탠드 룰렛 · 스크래치 렌탈) 정도, 인스타로 B2B 에 실제 현장 화면을 보여 주는 곳은 없음. 성수 뷰티 팝업은 「100% 당첨 럭키드로우」가 이미 표준 → **남은 수가 보이는 화면** · 박스 대신 화면이 차별점
- 쓰지 않는 말: 도박 · 베팅 · 잭팟 · 확률 · 이치방쿠지. `#럭키드로우` 는 신발 응모 글이 섞임 — 조합 「업종 + 지역 + 행위 + 구체 + #쿠벤팅」
- 홈페이지에 인스타 · 카톡 채널 연결이 없음 → 계정 생기면 추가. 처리방침에 「인스타그램 DM 문의」 항목도
- 박람회: IFS 프랜차이즈 10/22~24(토) 코엑스 C홀 · 서울카페쇼 11/11~14 · 푸드위크 11/4~7
