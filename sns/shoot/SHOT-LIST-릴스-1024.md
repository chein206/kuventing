# 주말 촬영(10-24 · 25) 릴스용 찍어 두면 좋은 컷 — 모션그래프 세션 제안 (10-19)

실촬영 릴스 두 편(손맛 · 카페)에 바로 붙일 수 있게. 편집은 지금 릴스 틀(위 그늘 + 큰 두 줄 · 판 녹화 섞기 · 끝 로고) 그대로.

## 공통
- **세로 4K 30fps**(또는 1080 60fps), 화면 밝기 최대 · 판 화면 반사 안 생기는 각도. 한 컷 5~8초씩 넉넉히(앞뒤 1초 여유)
- 위 250 · 아래 420 은 인스타 글자 자리 — **손 · 화면 · 경품은 화면 가운데~위 2/3** 에
- 실제 손님 얼굴은 안 나오게(손 · 뒷모습만), 다른 손님 얼굴이 뒤에 걸리지 않게(카드 02 「찍히는 자리」 그대로)
- 판은 데모 · 촬영용 판이면 「데모」 표시 붙임 — 실제 매장 판이면 그 매장 동의 받은 것만

## 손맛 편 (「밀어서 여는 맛」)
1. **손가락 클로즈업 — 표를 천천히 밀어 여는 3번**(빠르게 · 천천히 · 중간에 멈칫) — 이게 핵심 컷, 소리도 같이(판 소리 켠 채)
2. 손이 화면에 들어와 칸 하나 고르는 컷(위에서 · 옆 45°)
3. 결과 화면 나온 순간 손님 손이 경품 받는 컷(경품 실물 S8 이 손으로 넘어가는)
4. 화면 바깥 — 판 앞에 줄 선 발 · 뒷모습 2~3명(얼굴 X)
5. 느린 동작용: 120fps 되면 1번 한 번 더

## 카페 편 (「음료 1잔 = 1장」)
1. 주문 → 음료 나오는 손(컵 내려놓는 순간)
2. 카운터 위 태블릿 — 평소 광고판 상태 10초(케익 광고가 도는)
3. 손님 손이 태블릿 톡 → 표 고르기 → 밀어서 열기(손맛 편 1번 축소판)
4. 경품(케익 조각 · 음료 쿠폰) 실물이 접시 · 손에
5. 사장님 폰에서 쿠폰 사용 처리하는 손(가능하면)

## 판 녹화로 채울 수 있는 것(안 찍어도 됨)
- 화면 속 판 움직임 · 남은 수 · 결과 화면은 1080 녹화가 더 선명 — 실촬영은 **손 · 사람 · 실물 · 공간**에 집중
