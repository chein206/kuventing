# 촬영 1회차 — 태블릿에 손 넣어서 (주말 15~20분)

찍은 원본은 **폰에서 그대로** 구글 드라이브 `CLD/kuventing/sns/shoot/01_raw/` 에 올려 주세요(카톡으로 보내면 화질이 깨져요).
말은 안 하셔도 돼요. 판 소리가 같이 녹음되게 주변만 조용히.

## 준비 (5분)

**태블릿 (Tab S9 Ultra, 세로)**
- 밝기 최대 · 자동 밝기 끔 · 방해 금지 켬 · 화면 지문 닦기
- 크롬으로 아래 주소를 탭 다섯 개에 열어 두기. 화면을 한 번 만지면 전체화면이 돼요(주소창 · 「데모」 띠 없음)
  - `kuventing.scpadlab.com/demo/beauty?shoot=1` 뷰티 팝업
  - `kuventing.scpadlab.com/demo/cafe?shoot=1` 카페
  - `kuventing.scpadlab.com/demo/chicken?shoot=1` 치킨 호프
  - `kuventing.scpadlab.com/demo/arven?shoot=1` 시승 행사
  - `kuventing.scpadlab.com/demo/food?shoot=1` 라멘집
- 판 소리는 켜져 있어요. 태블릿 볼륨은 중간 이상
- 판을 처음 상태로 돌리고 싶으면 새로고침

**폰 (찍는 쪽)**
- 세로 · 4K 30fps (S2 만 1080p 60fps 면 더 좋아요) · HDR 끔 · 렌즈 닦기
- 태블릿 화면을 길게 눌러 초점 · 밝기 고정 → 밝기 막대를 살짝 내리기(화면 글자가 하얗게 날아가지 않게)
- 형광등 아래에서 화면이 줄무늬로 깜빡이면: 프로 동영상 모드 → 셔터 1/60

**주변**
- 회사 · 차 브랜드 물건, 서류, 명함이 안 보이게
- 태블릿 화면에 얼굴이 비치지 않게(천장 조명 반사도 각도로 피하기)

## 찍을 것 (한 장면 10~15초, 두 번씩)

| # | 장면 | 어떻게 | 업종 |
|---|---|---|---|
| S1 | **위에서 내려다보기** | 태블릿을 책상에 눕히고 폰을 바로 위에서. 손 없이 2초 → 손이 들어와 탭 → 표 고르기 → 밀어서 열기 → 결과에서 2초 멈춤 | 뷰티 · 카페 · 치킨 |
| S2 | **손끝 가까이** | 45도로 가까이, 표를 밀어 여는 순간만 화면 가득. 천천히 한 번, 보통 속도로 한 번 | 뷰티 · 치킨 |
| S3 | **손님 눈높이** | 태블릿을 세워 두고(거치대나 책에 기대기) 어깨 너머에서. 광고판이 돌다가 손이 탭 → 럭키드로우로 바뀌는 순간 | 시승 · 카페 |
| S4 | **그냥 두기** | S3 자리 그대로, 손 없이 광고판만 15초. 폰은 고정(책에 기대기) | 다섯 다 조금씩 |
| S5 | **놓기만 하면 끝** | 빈 책상에 태블릿을 툭 놓고 세우는 3초 → 화면이 켜져 있는 상태 | 아무거나 |
| S6 | **진짜 물건 옆에** | 책상 위 커피잔 · 화장품 · 작은 상자를 태블릿 옆에 두고, 판에서 그 경품이 나오는 장면 | 카페(잔) · 뷰티(화장품) |
| (S7) | 쿠폰 찍기 | 다른 폰이 있으면 — 결과 화면의 쿠폰을 손님 폰으로 찍는 손 | 선택 |
| S8 | **경품 실물 사진** | 커피 · 케이크 · 화장품 등 실제 물건을 한 장씩, 위에서 · 정면에서. 판 안의 경품 사진(지금은 AI 생성)을 이걸로 바꿔요 — 가까이 찍어도 「AI 음식」으로 안 걸리게 | 카페 · 뷰티 |

## 왜 이렇게

- 진짜 손 · 진짜 화면 · 진짜 소리가 「AI 로 만든 광고」처럼 안 보이게 하는 제일 센 재료예요
- S1 · S2 는 손맛 릴스, S3 · S4 는 「평소엔 광고판, 누르면 럭키드로우」, S5 는 「기기에 비치만 하면 끝」, S6 은 「상품만 정하세요」에 들어가요
- 흔들림 · 조명 정도는 편집에서 잡아요. 완벽하게 안 찍으셔도 돼요
