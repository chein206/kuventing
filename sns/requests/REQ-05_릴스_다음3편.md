## 07 고침(대표 10-19) — 기사 인용 훅

대표: 「홍대에서 쿠지 다 깠는데 1등이 안 나온 기사 인용하면 안 되나 — 다 나오는 게 아니라 마스킹 들어가면서 타이틀 정도만」

- 기사: **시사위크 · 김지영 기자 · 2026.8.21 「1등 없는 뽑기?… '쿠지'는 규제 사각지대」** (https://v.daum.net/v/ZOJgzAFYS4)
- **0~2.5초 훅**: 우리가 직접 조판한 「기사 카드」 — 제목 한 줄만 또렷, 본문 줄은 흐림 · 막대로 가림, 아래 작게 「시사위크 · 2026.8.21」. 이어서 위 글자 「다 깠는데 / 1등이 없었다」
- 그다음은 원래 07 흐름: 우리 판 끝물 — 「1등이 아직 안 나왔어요 / 남은 건 7장」, 등급별 남은 수가 화면에 보이고 손님이 고를 때마다 줄어듦 → 「남은 경품이 화면에 실제로 보여요」 → 로고
- **지킬 것**
  - 기사 화면 캡처 · 기사 사진 쓰지 않기(사진도 기사 저작물) — 제목 글자만 우리 디자인으로 다시 쓰고 출처 표기
  - **매장 이름 · 인스타 · 위치 디테일 · 작품 이름(블리치) · 「이치방쿠지」 쓰지 않기** — 특정 업체를 겨냥한 비방 광고로 보이지 않게. 「홍대」 「캐릭터 굿즈 매장」 정도까지만(기사 제목엔 매장 이름 없음)
  - 「조작」 「사기」라고 단정하지 않기 — 매장은 「직원 실수로 누락」이라고 사과함. 우리 말은 「손으로 관리하는 판은 확인이 어렵다 → 화면은 남은 수가 보인다」 쪽으로
  - 「뽑기 · 꽝 · 당첨」은 기사 제목 안에서만(인용), 우리 자막은 럭키드로우 · 경품
