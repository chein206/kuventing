# 04 캐러셀 캡션 — 상품만 정하세요

## 캡션

```text
팝업 · 매장 럭키드로우, 사장님이 하실 일은 하나예요

판 디자인은 가게 분위기에 맞춰 저희가 만들어요
메뉴 · 상품 · 경품 사진이 없으면 그것도 만들어 드려요
평소엔 광고판으로 돌아가고, 손님이 누르면 럭키드로우가 돼요
태블릿, 스탠드형 화면, 키오스크에 주소 하나 열면 시작해요

사장님은 어떤 경품을 몇 개 둘지, 한 장을 주는 기준만 정하시면 돼요.
남은 수와 쿠폰은 사장님 폰에서 바로 확인해요.

도입 문의는 프로필 링크나 DM으로 주세요. 데모도 거기서 직접 열어 볼 수 있어요.

#팝업이벤트 #매장이벤트 #오픈이벤트 #자영업자 #쿠벤팅
```
