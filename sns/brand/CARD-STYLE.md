# 쿠벤팅 카드뉴스 스타일 (10-19 대표 OK 시안 기준 · 모션그래프 세션)

대표가 말한 「AI 티」 = 정형화된 카드뉴스 틀. 음식 · 상품 · 판 사진은 써도 된다. 틀을 깨는 게 목적.

1. **안 쓰는 것**: 큰 번호(01 · 02…) + 작은 회색 말, 붓 밑줄, 아래 진행 표시, 칸 나눈 카드 격자, 빈 상자 · 노랑 막대 그림, 매 장 「~해요」 두 줄 + 셋째 줄 굵게 반복.
2. **장마다 구도를 다르게**: 3~4가지를 섞는다 — 실물 크게(가장자리 밖으로 잘리게) · 한 문장만 크게 · 노랑 판 뒤집기(편당 1장) · 크림 종이 판(편당 1장 이하).
3. **현실 물건으로 말하기**: 점검표 클립보드 · 포스터 + 메모지 · 영수증(지그재그 아래) · 서식 + 도장 · 작업 의뢰서(작성 완료 도장 + 비어 있는 사장님 칸) · 위에서 본 배치도.
4. **실물 화면 · 사진**: 판은 실제 녹화 프레임(`posts/01_signage_reel/rec/clips/*` 에서 뽑기), 베젤 안에 살짝 기울여. 판이 보이면 「실제 판 화면 · 데모」 알약 하나.
5. **넘김 = 밀어서 열기**: 1→2장처럼 표 하나가 두 장에 걸치고, 넘기면 절취선에서 윗장이 젖혀지며 안쪽이 드러난다(뒷면은 로고 남색 #233253).
6. **앞뒤 짝**: 표지와 끝 장을 같은 물건으로(예: 빈 점검표 → 다 체크된 점검표).
7. **글자**: 제목 블랙한산스 84~104px 두 줄 안, 본문 프리텐다드 30~34px 두 줄 안, 강조(굵게 · 노랑)는 편 전체에서 1~2번. 문장 길이를 섞고 대표 말투 그대로.
8. **틀**: 1080×1350, 위 왼쪽 마크 + KUVENTING · 위 오른쪽 「n / N」 · 아래 왼쪽 @kuventing — 이것만 매 장 같다.
9. **색**: 밤 남색 #070B16 · 노랑 #FFC83D 하나 · 크림 #F3F1EA · 로고 남색 #233253. 금빛 · 빛줄기 · 도박 기호는 우리가 덧대지 않는다(판 화면 원래 연출은 그대로).
10. **숫자**: 판에 실제로 보이는 것 · 법정 수치(제세공과금 22% 등)만. 계산 예시는 「예시」 표기, 정할 값은 ○○.
11. **끝 장 CTA**: 「데모는 프로필 링크에서 직접 열어 보세요 · 도입 문의는 DM」 + 마크.
