# 사진 판 원판 — 여기에 넣는다

`photo-letterpress` · `photo-brass` 테마가 읽는 파일이다.
없으면 종이색과 번호만 남는다 (화면이 깨지지는 않는다).

클로드 디자인 프로젝트 `뽑기 보드 · 사진`의 `assets/photo/` 에서 그대로 가져오면 된다.

| 파일 | 무엇 |
|---|---|
| `ticket-letterpress.png` | 활판 입장권 원판. 배경 없는 투명 PNG, 천공이 실제로 뚫려 있다 |
| `ticket-brass.png` | 황동 포일 원판 |
| `ticket-mini.png` | 미니 칸(69×49) 전용 원판. 괘선 한 줄 + 여백뿐 |
| `stamp-geom.png` | 검인 도장 (검 · 주홍). 잉크 농담이 알파에 들어 있다 |
| `seal-wax.png` | 밀랍 봉인. 가운데가 비어 있어 글자를 얹는다 |
| `handle-brass.png` | 개봉 화면 황동 레버. 가로로 찍힌 것을 코드가 세워 쓴다 |
| `surface-oak.jpg` | 판 표면. 이음새 없이 반복된다 |

## 왜 자동으로 못 받아왔나

디자인 MCP 의 `get_file` 은 **256 KiB 에서 자른다**. 원판 사진은 그보다 커서
받으면 잘린 채로 온다(실제로 세 장을 시도해 셋 다 잘렸다). 그래서 파일만 손으로 넣는다.

## 재는 값

사진마다 **천공 열 위치가 다르다**. 원판을 새로 넣으면 `lib/boardArt.ts` 의
`perf` 값을 다시 재야 한다 — 안 그러면 번호가 천공 위로 올라탄다.

```
활판  73.8%   검표 마닐라  64.5%   황동  75.6%   미니  72.7%
```

**여러 원판을 한 판에 섞어 쓰면 안 된다.** 천공 자리가 칸마다 달라 보인다.
