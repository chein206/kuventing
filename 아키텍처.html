쿠벤팅 Architecture

꽝 없는 등급제 뽑기 · Next.js 16 + Supabase · 테이블 직접 접근 0, 모든 경로가 security definer RPC 뒤에 있다

신뢰 경계 3개

  • • anon key — 화면이 부르는 6개 함수만. 나머지 19개는 회수됨
  • • ownerToken + PIN — 사장님 화면. 토큰만으로는 못 연다
  • • JWT + admins — 어드민. Auth 통과 후 화이트리스트 재확인
  • • RLS 켜짐 · 정책 0개 → 테이블 직접 접근 경로 자체가 없다
  • • 주의: revoke ... from anon 은 기본 EXECUTE TO PUBLIC 을 안 지운다. 016 이 그 구멍을 막았다

바깥에 안 맡긴 것

  • • 광고 — MP4 안 굽고 데이터로 CSS 애니메이션. 메뉴 바뀌면 광고도 같이 바뀐다
  • • 소리 — Web Audio 합성. 음원 파일 0개, 로딩·용량 0
  • • 종이결 — feTurbulence. 타일 PNG 안 받는다
  • • 이미지 처리 — 브라우저 Canvas. 서버는 헤더만 파싱해 재검증
  • • QR — 클라이언트 생성. 서버 왕복 없음

데이터 흐름 한 바퀴

  • 1. 손님이 태블릿을 누른다 → open_session (직원 PIN)
  • 2. 50칸 중 하나 선택 → draw 가 등급·쿠폰을 확정
  • 3. tickets UPDATE → Realtime 이 같은 매장 태블릿 전부에 밀어냄
  • 4. 손님 폰이 QR 로 /c/[id]/[code] 열람
  • 5. 사장님 화면에서 redeem 으로 사용 처리
